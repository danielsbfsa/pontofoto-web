# Ponto Foto (web)

Registro de ponto pela foto do comprovante, banco de horas e conferência do espelho de ponto.

**Abrir/instalar:** https://danielsbfsa.github.io/pontofoto-web/

No iPhone: abra no Safari → Compartilhar → Adicionar à Tela de Início.

Os dados ficam só no aparelho de cada pessoa; nada é enviado para este repositório.
